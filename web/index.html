Every few hundred milliseconds a System One model reads the fight, weighs every move, and picks one. You write the strategy. It supplies the reflexes.

Fighter Lab

Your fighter is a paragraph of English plus a few optional reflexes. Each decision, the brain gets the fight state, your strategy as the instruction, and every legal move as a choice. Reflexes are yes/no checks with a threshold that override the strategy when they fire.

Game AI written in English, run at reflex speed

        
LLMs are great at thinking and terrible at twitch reflexes: by the time one has written its answer, the heavy shot has already landed. System One models such as TypeSafe's Jev don't write text. They read a state and return typed decisions with calibrated probabilities in a few hundred milliseconds, which is fast enough to pilot a fighter in real time.

        

          
1 · StateThe engine turns the fight into plain facts. "enemy charging heavy shot: YES, fires in 0.4s"

          
2 · QuestionsYour strategy becomes a Choice over every legal move. Each reflex becomes a Noul (yes/no).

          
3 · Typed answerThe brain returns a probability for every move and every reflex, plus a confidence.

          
4 · MoveA fired reflex wins. Otherwise the top move, if the brain is confident enough. Otherwise your fallback.

        

        
Real-time vs lockstep

        
In real-time mode the world never waits: a brain is asked again as soon as it answers, so a 250 ms brain acts four times a second and a 3 s brain barely acts. In lockstep mode the world freezes every 0.2 s until both brains answer, so only decision quality counts. Try the same fighter both ways with a slow brain.

        
Brains

        
    
          
  • Jev: TypeSafe's System One model, the headliner. Set TYPESAFE_API_KEY and run npx jev-arena.
    • 
          
  • Laya, kev and other open models: anything that speaks the System One HTTP protocol. Point JEV_ARENA_ENDPOINTS at it.
    • 
          
  • Any chat LLM (OpenAI, OpenRouter, Ollama...): translated to JSON prompts, for comparison. Its probabilities are self-reported, not calibrated.
    • 
          
  • Mock: offline keyword heuristics, so the arena works with no key at all. It is not smart.
